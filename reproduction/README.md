# NLPrompt 复现 / Reproduction of NLPrompt (CVPR 2025)

- 论文 / Paper：[NLPrompt: Noise-Label Prompt Learning for Vision-Language Models](https://arxiv.org/abs/2412.01256)（CVPR 2025 Highlight）
- 官方代码 / Official code：[qunovo/NLPrompt](https://github.com/qunovo/NLPrompt)，commit `b36bc8e`。本仓库根目录就是这份代码，**没有改动**，提交历史保留。我们只加了 `reproduction/` 这个文件夹（复现脚本、结果和日志）。

## 学习率 / Learning rate

官方脚本 `scripts/nlprompt/main.sh` 默认扫多个学习率（`LR_LIST="0.001 0.0006 0.0007"`）和 10 个种子（`SEED_LIST="0 … 9"`）。**我们只取了一个学习率：0.002**，即配置文件 `configs/trainers/NLPrompt/rn50.yaml` 和论文 6.3 节写的值，每个设定只跑种子 1。所以复现结果和论文表 1 有出入，75% 噪声下差得最多。

The official script `scripts/nlprompt/main.sh` sweeps several learning rates (`0.001 0.0006 0.0007`) and 10 seeds by default. **We used a single learning rate, 0.002** (the value in `configs/trainers/NLPrompt/rn50.yaml` and Sec. 6.3 of the paper) and a single seed (seed 1) per setting, so our numbers differ from Table 1 of the paper, most at 75% noise.

| 项 / Item | 本复现 / Ours | 官方脚本默认 / Official script default |
|---|---|---|
| 学习率 / Learning rate | **0.002**（只取一个 / single） | 扫 / sweep 0.001, 0.0006, 0.0007 |
| 种子 / Seeds | 1 | 0–9 |
| OT 熵正则 / `DATASET.REG_E` | 0.01（`train.py` 默认值 / default） | 0.001 |
| 骨干 / Backbone | CLIP RN50 | 同 / same |
| 其余 / Others | 16-shot，200 轮，SGD + 余弦退火，batch 32，16 个上下文 token / 16-shot, 200 epochs, SGD + cosine, batch 32, 16 context tokens | 同 / same |
| `DATALOADER.NUM_WORKERS` | 4（配置文件是 0，只影响读图速度 / config has 0; speed only） | 0 |

数据集和噪声：Caltech101、DTD、Flowers102；对称（sym）/ 非对称（asym）噪声 × 25% / 50% / 75%，噪声由官方代码按种子生成。
Datasets and noise: Caltech101, DTD, Flowers102; symmetric / asymmetric noise at 25% / 50% / 75%, generated by the official code.

## 环境 / Environment

RTX 4090 D（24GB），Python 3.10，PyTorch 2.4.0 + CUDA 12.1，torchvision 0.19.0。一次 200 轮的运行约 30–50 分钟（多个运行共用一张卡时）。
RTX 4090 D (24GB), Python 3.10, PyTorch 2.4.0 + CUDA 12.1, torchvision 0.19.0. One 200-epoch run takes about 30–50 minutes when several runs share the GPU.

安装时和官方说明的两处不同 / Two differences from the official install instructions:

- 清华源没有 `tb-nightly`，换成了 `tensorboard`（只用来写训练曲线）。/ `tb-nightly` is not on the Tsinghua mirror; we installed `tensorboard` instead (only used for logging curves).
- `Dassl.pytorch` 用 `pip install --no-deps -e .` 安装（依赖已单独装好）。/ `Dassl.pytorch` was installed with `pip install --no-deps -e .` (dependencies installed separately).

## 数据 / Data

目录结构按 CoOp 的 [DATASETS.md](https://github.com/KaiyangZhou/CoOp/blob/main/DATASETS.md)。DTD 和 Flowers102 从牛津官网下载；Caltech101 的官方地址在我们的服务器上返回 403，改用 Hugging Face 上 [HuggingFaceM4/Caltech-101](https://huggingface.co/datasets/HuggingFaceM4/Caltech-101) 的同一个 `caltech-101.zip`。划分文件 `split_zhou_*.json` 和 `cat_to_name.json` 来自 CoOp 的 Google Drive 链接。

Layout follows CoOp's DATASETS.md. DTD and Flowers102 come from the Oxford VGG site; the official Caltech101 URL returned 403 on our server, so we used the same `caltech-101.zip` from HuggingFaceM4/Caltech-101 on Hugging Face. The split files come from CoOp's Google Drive links.

## 复现步骤 / How to run

在仓库根目录 / from the repository root：

```bash
bash reproduction/scripts/setup_env.sh          # 建 conda 环境 nlprompt / create the env
conda activate nlprompt
bash reproduction/scripts/get_data.sh           # 下载数据到 ./data / download data to ./data
bash reproduction/scripts/run_one.sh caltech101 sym 0.5 1     # 单次 / one run
P=2 bash reproduction/scripts/run_all.sh        # 全部 18 个设定，同时 2 个 / all 18 settings, 2 at a time
python reproduction/scripts/summarize.py        # 汇总并和论文对比 / summarize vs. paper
```

- CLIP RN50 权重第一次运行时自动下载；也可以把 `RN50.pt` 放到 `clip/RN50.pt`。/ CLIP weights are downloaded on first use, or put `RN50.pt` at `clip/RN50.pt`.
- 每个运行会把训练集和测试集图片读进内存（Flowers102 约 7–12GB）。内存不够时把 `P` 设成 1。/ Each run loads the train and test images into RAM (about 7–12GB for Flowers102); use `P=1` on smaller machines.
- 这些脚本整理自我们实际运行用的脚本，只把服务器上的固定路径改成了可配置的（`DATA`、`OUT_ROOT`）。/ The scripts are tidied versions of the ones we ran; only the hard-coded server paths were made configurable.
